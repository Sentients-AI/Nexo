# Nexo

**Nexo** is the commerce engine powering
[aljebal-albeedos](https://github.com/Sentients-AI/Nexo).

It is an Arabic-first, multi-vendor marketplace platform designed for the
Sudan market.

## Product

aljebal-albeedos provides a single marketplace where independent vendors
can sell through one storefront while shoppers can discover products from
multiple vendors and complete a single checkout.

## Engineering

Nexo is built around:

- explicit domain boundaries;
- vendor-context isolation;
- transactional workflows;
- idempotent money movement;
- automated testing;
- auditability;
- architecture decision records;
- continuous integration.
